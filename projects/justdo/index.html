JustDo

Django REST Framework · React · Vite · JWT

A minimal, elegant todo app for people who want to organise tasks without the clutter.

What it does

JustDo lets you quickly add tasks, tag them by category, and drag and drop them into priority order. You can filter by tags, switch between dark and light modes, and stay focused on what matters.

Tech stack

The backend uses Django REST Framework with JWT authentication. The frontend is built with React and Vite, with SQLite for development and support for PostgreSQL in production.
