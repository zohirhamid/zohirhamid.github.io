Project · 2025

TRACKED

Django · PostgreSQL · Stripe · Railway

A minimalist habit tracker for professionals who value speed and clarity over gamification.

What it does

TRACKED uses an Excel-like grid for fast daily logging. It supports custom trackers, multiple data types, and weekly summaries, with Stripe-powered subscriptions.

Tech stack

The application is built with Django and PostgreSQL, uses Stripe for billing, and is hosted on Railway.
